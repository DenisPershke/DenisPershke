### 🛠 Избранные проекты

* **[Taskly](https://github.com/DenisPershke/Taskly_board)** — Асинхронный сервис управления задачами.
  * *Стек:* FastAPI, React, PostgreSQL, Docker.
  * *Архитектура:* REST API, JWT-авторизация, реляционное хранение данных, контейнеризованный деплой.

* **[FriendParty](https://modrinth.com/plugin/friendparty)** — Серверный модуль синхронизации пати и взаимодействия игроков для Minecraft.
  * *Стек:* Java, Paper/Spigot API.
  * *Фокус:* Обработка событий в реальном времени, потокобезопасная маршрутизация пакетов, интеграция с Modrinth.

* **[FishPvE](https://modrinth.com/plugin/fishpve)** — Модуль кастомных PvE-механик и лут-генерации.
  * *Стек:* Java, Spigot API.
  * *Фокус:* Кастомные тайминги, механика взаимодействия сущностей, система вознаграждений.

* **Admin Toolset (Arizona RP)** — Скрипт и утилит для администрирования серверов.
  * *Стек:* Lua, Python.
  * *Фокус:* Автоматизация рутинных процессов, парсинг логов, валидация игровых сессий.

* **ViceCity Mod** — Модульный Discord-бот для управления и модерации игровых сообществ.
  * *Стек:* Python, Discord API.
  * *Фокус:* Ролевая модель доступа, логирование действий, обработка очередей.
